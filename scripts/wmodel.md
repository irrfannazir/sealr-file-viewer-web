## Attribute : `wmodel`

**Applies to:** any
**Type:** String
**Category:** Element-specific

**Description**
It behaves as the model is programmed. Assign the model name to it as string.

**Syntax**
```html
    <element wmodel="dir" class="ls-dir">
```

### Models
`dir` **:**
    It displays the directory details from 'fileManager/dir.js', starting from "root". It redirects to each folders selected. It displays the file in the element with id `fileCanvas`.

`mobile-man` **:**
    It enables the Mobile Mode. It shows the directory same as dir.  It will switch the elements `fs-b1` and `fs-b2`, when the file is opened.
